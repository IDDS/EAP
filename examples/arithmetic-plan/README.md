# 计算与核验团队

用公开的 `1 + 2` 验证 EAP 的创建、部署、编排、结果契约和观测链路。

本样例通过控制台完成，操作步骤见[从控制台到一次多智能体执行](../../docs/GETTING_STARTED.md#4-创建计算--核验团队)。需要已接入运行系统、模型网关和实例身份的环境；控制台开发预览无法直接调用模型。

| 成员 | 步骤 | 预期结果 | 结构契约 |
| --- | --- | --- | --- |
| Calculator | 计算 `1 + 2`，只输出 JSON | `{"sum":3}` | 必填字段 `sum`，类型 `number` |
| Verifier | 读取上一结果并检查其值 | `{"verified":true}` | 必填字段 `verified`，类型 `boolean` |

每个成员设置一次模型调用额度，输出上限可设为 256 Token。先保存计划与契约，再提交一次；保存原执行编号，用它查看步骤、预算和观测。

结构通过并不保证值正确。验收须同时确认 `sum = 3`、`verified = true`、两个步骤完成、调用归属正确及实例按预期挂起。模型失败、UNKNOWN 或额度不足时停止，保留原回执，不改编号自动重试。
