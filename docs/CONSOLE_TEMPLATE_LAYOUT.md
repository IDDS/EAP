# EAP 控制台模板布局

设计日期：2026-10-28。目标是让用户知道自己在哪、下一步做什么、在哪里查看执行证据。

## 参考与实际复用

- [AdminLTE 布局](https://www.adminlte.io/themes/v4/docs/layout.html)与[布局结构](https://www.adminlte.io/themes/v4/docs/layout-blueprint.html)：采用侧栏、顶栏、内容区的固定分工。
- [官方 Vue 组件](https://github.com/ColorlibHQ/adminlte-vue)：使用项目已锁定的 `@adminlte/vue@0.7.0`，在 `App.vue` 使用 `LteAppContent`，在 `WorkspaceStart.vue` 使用 `LteCard`。运行大屏原有指标组件继续复用。
- [Vue Pure Admin](https://github.com/pure-admin/vue-pure-admin)：参考其 Vue 与 Element Plus 管理后台的职责划分，没有复制其代码或增加依赖。

以上来源访问于 2026-10-28。没有直接替换为完整 `LteDashboardLayout`：EAP 保留自己的企业认证、权限、搜索和移动导航。卡片使用作用域样式适配现有设计变量，没有全局引入 Bootstrap 样式。

## 信息布局

侧栏只有“工作区 → 功能”两层。观测、评估、治理等功能直接进入各自的分区，不再依次展开“工作区 → 页面 → 分区”。智能体详情仍保留具体智能体上下文，目录入口始终可用。

工作台的开始工作、待办事项、运行指标、协作拓扑也放在侧栏。首页按“准备智能体 → 安排协作 → 跟进执行 → 核对结果”介绍操作顺序，另提供执行记录和调用链入口；统计只使用现有接口返回的数据，尚未取得数据时显示 `—`。

顶栏提供当前位置、全局搜索、字号与认证入口。内容区由每个页面说明当前任务；例如工具分区显示“工具与 MCP 调用”，避免所有观测分区都叫“调用与链路”。模型遥测提示仅显示在运行总览与模型分区。表格保持筛选在上、分页在下。

## 视觉与交互约定

沿用现有中文系统字体与 EAP 的墨色文字、灰白背景、青色操作强调；错误、警告、成功分别使用现有语义色。卡片采用 4px 圆角、细边框和明确的标题、内容、页脚区域。一级工作区与二级链接有统一缩进、行高、当前状态和键盘焦点。

桌面侧栏宽 248px，折叠时 72px；900px 以下使用抽屉。首页流程在中等宽度变为两列，600px 以下为一列。内容列设置 `min-width: 0`，避免宽表格撑开整个页面。

## 状态归属与验证

`navigation/catalog.ts` 定义工作区与功能入口；`PlatformNavigation` 仅管理展开状态。`usePageSection` 从 URL 读取分区，支持刷新、后退、收藏链接，并保留当前页面的筛选上下文。切换到其他页面不继承当前页面的智能体或 Trace 筛选。

权限仍以 `/api/platform/me` 的能力为准。布局调整不触发任务、审批或重试，也不把工作流派发记录当作真实 Trace。远程测试结果与上线状态记录在本次交付证据和 `PROJECT_MEMORY.md`，本文件本身不代表已通过验收。

## 全站一致性

所有 22 个常规页面（20 个业务入口、工作台、智能体详情）统一使用 `ConsolePageHeader`；认证回调和运行大屏保留各自的独立布局。标题与分区说明由导航目录统一提供，页面通过操作插槽保留实际权限控制和事件处理。反馈的实验/优化记录继续显示具体记录类型，智能体详情额外标明当前智能体。

页头统一使用简洁标题、任务说明和右侧操作区，在窄屏自然换行。移除原页面首屏重复的眉题、巨大标题和多套页头布局；导航和页面使用同一套功能名称。预算页隐藏无关的币种和模型统计操作，工具页不显示自主发现和模型缺失提示，运行环境发现使用其自身的查询控件。

样式维护同时删除已经移除的工作台顶部标签、旧首页入口、旧页头和详情顶栏选择器，合并 Dashboard 的三段重复作用域样式。新页面通过共享组件继承页头约定，避免再增加逐页覆盖规则。
