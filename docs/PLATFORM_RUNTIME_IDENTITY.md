# 平台创建实例的专属身份

本合同覆盖通过 EAP 发布新 `RUNNER` 版本后创建的平台实例。已复核外部实例的配送协议见 [安全自动接入](RUNTIME_AUTOMATIC_IDENTITY.md)。本项把实例所有权、接入身份和创建请求连起来，修正版默认运行程序适用入口为工作流任务、对话和平台提示词实验；不等于整个 T5 或系统主线完成。

## 创建、身份与版本

新 `RUNNER` 提交冻结 `PER_INSTANCE_V1`、固定 Runner 镜像及平台配送公钥。黄金模板只配置 Agent、网关地址、模型、提示词和只读 `systemInfo.actorMetadata` 三字段目录，不注入共享任务/网关/观测凭证、供应商密钥或控制 API 服务账号。配送私钥继续使用已有不可变集群 Secret，不旋转旧身份或改写旧模板。

创建前保存固定 UUID、部署版本、实例名称和独立配送请求。原生 Create 返回的 UID 才能建立平台所有权，不接受普通注册/心跳自行声明身份。实例行保存平台 UID/模板，与外部纳管 UID 分开；EAP 身份周期、短凭证版本及工具根/操作/效果沿用原合同。UID 不代表原生分配代次。

同一创建请求固定原部署版本，即使后来发布新版本也不会换实例或模板。原生创建回执不明确时保留 `attempted` 和原请求，不再 Create、不删除重建、不凭同名实例接管。此时需管理员核对，通用恢复另属 T6。已确认 UID 后的策略或接入失败，可以核对原 UID 后继续原阶段。按需续期的配送回执未确认时，固定创建请求可能返回另一配送待核对；管理员应按接入状态中的原 deliveryOperation 核对同一配送，再查询原创建请求，禁止新批准、换身份或重新Create。通用自动对账与恢复仍属T6；已存在的出站策略先读取其 UID/版本，一致规则不更新，确需替换时携带版本前置条件，并发冲突不盲目重试。接入未确认时版本不能显示可运行。

## 配送、撤销与执行

部署流程新增“专属身份接入”：原生实例创建 → 加密配送 → 实例回执确认 → 可运行。创建动作批准该实例最多 24 小时接入授权，默认短凭证 900 秒；前端明确说明授权含义，只有 `/platform/me` 相应能力能创建或操作。平台创建实例仅走自动配送，不展示或提供人工凭证下载。

配送签名/挑战/内存 RSA-OAEP/只读 UID 校验/HMAC 回执和按需续期复用安全自动接入合同。确认之前候选不可在 EAP 使用。工作流、对话及实验派发之前复核原生 UID/模板并安装有效短凭证。身份元数据不完整、已撤销或实例下线时拒绝执行，不回退共享凭证。空闲不因续期主动唤醒。已明确批准的创建请求在短凭证到期后核对原实例时，按原身份周期续期并恢复休眠；不延长24小时接入授权，不新建实例、工具根或业务意图。

撤销保留接入及创建历史，原创建请求永久标记取消。即使之后人工显式重新批准同一实例，旧创建请求仍不能重新启用它。删除已绑定实例先复核身份、撤销，再调用原生删除，保留 OFFLINE 身份墓碑及授权、操作、效果和预算；不删除历史以伪装成全新实例。

## 受控计数标识符与内容检查

`controlled_counter_increment` 的 `grantId/operationId/resourceId` 是合同标识符，`delta` 是有界整数。只有工具存储先核对类型、所有权、作用域及祖先授权后，内部检查才按合同元数据进行安全判断；原始参数仍参与操作指纹、预算、存储确认效果和审计关联。避免把合法 UUID 中的数字片段误判成手机号。

此处理不开放给普通工具检查 API，也不由调用方选择。普通参数继续检查全部键和值，即使工具名相同，也不能用标识符声明跳过敏感检查；未知字段在受控 API 入口拒绝。生产业务工具必须逐个定义内容及标识符语义，本项不替它们作统一豁免。

## 受控任务工具与独立实验

受控工具任务是否启用，与独立实验的工具能力分别定义。修正版运行程序允许两条入口共存，实验固定两个全新system/user消息，不读取对话历史，不向模型提供工具定义；模型返回工具调用时结果保持UNKNOWN，不执行工具、不重发。实验仍需要持久化意图日志、实例认证、服务端冻结配置及共享模型预算。

实测初版v1受控工具标志关闭了实验接口，原400/404记录和一次成功对话保留。修复经旧代码红测、修正版完整竞态及编译验证后，仅发布显式v2新实例；原两个v1实例及模板、UID、创建请求和工具效果不变。同一额外创建请求在发布v2后仍指向v1原实例。旧运行程序未原地升级。

## 实验编号、预算与观测

实例自报编号默认按实例空间隔离。仅EAP已保存的实验试验编号，且智能体、实例键、原生UID、模板和端点都与冻结记录一致，才保留服务端分配的全局编号；其他实例、重建UID不能借用。模型准入仍核对试验/实验RUNNING及不可变意图，已结束或未知不能转成普通调用。观测沿用同一服务器解析器，Span ID继续隔离、外来身份拒绝、跨实例links仍移除；没有HTTP调用方豁免标志。

首次v2实验两调用已经完成，但实例编号转换造成实验预算未关联；其原结算仍计入智能体/平台且全部保留，不倒填、重发或清零。修复后使用不同公开样本的新有界实验，核对两个冻结试验与网关和实验预算一一关联，旧/新已结束原意图和外来实例拒绝、新增调用零。实验协议目前只记录网关/试验追踪，不发独立AGENT Span；原对话Span核对既有历史，不把到期接入状态的空字段当成记录丢失。T7观测完善仍待。

## 前端与兼容边界

额外会话创建使用固定请求编号，页面失败/重开保持原编号；成功响应按原 Agent/用户核对。最新已完成版本不支持专属身份时，入口禁用并说明需发布新版本。新流程显示六阶段，手机纵向排列；环境清单显示“平台专属身份”，接入抽屉显示授权期与公开配置，不出现秘密材料。

已有模板/快照不自动迁移。旧 `RUNNER`、`IMAGE` 和 `SOURCE` 首次版本创建保留旧路径；额外会话 API 要求发布支持专属身份的新版本，旧版本当前不能新增会话。任务网络独立执行器、自主出站和超长任务、旧共享凭证模板迁移仍属后续阶段。内部可信 HTTP 路由 PoC 不等于生产 mTLS/原生分配代次/完整灾备。实际测试、发布、效果与范围以本轮验收和交接记录为准。

## 验收约束

使用独立测试 Agent 和两个初版v1实例、一个显式修正版v2实例，固定请求核对重复原创建请求不新增实例、两初版 UID/身份独立、跨实例凭证拒绝；一次工具工作流只有一个存储确认效果且模型零调用；原v1一次对话、v2首次公开单样本对照实验两调用，以及修复后不同公开样本的独立对照实验两调用，共五个模型调用（含保留的首次完成但预算未归属的两调用）。该实验只验证执行入口，不证明调优收益。四角色 API 与桌面/手机真实浏览器按能力检查，浏览器业务写入零。

收尾休眠三实例、撤销身份与工具根、停用策略，核对原请求拒绝、零原生变更、原效果和共享预算保留。所有旧 T1–T5-B 对象、UNKNOWN、模板/快照及持久认证保持，不能重放旧意图或重置预算。全部依赖、测试、构建、部署和浏览器在远程执行，本机只编辑文本、检查摘要与脱敏证据；无 commit/push。
