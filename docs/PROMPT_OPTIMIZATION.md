## 版本与范围

GEPA 固定发行版 0.1.4、MIT、Python 3.12；wheel 摘要 `12b971039599625c156d2231f6d72a29c31a22e9c237689459b5f1a3c353f532`。采用基础安装、不带额外模型/RAG/跟踪依赖；实际优化调用固定 adapter，无默认供应商客户端、embedding 或云跟踪出口。

仅平台托管、固定 Runner digest 的 `STATELESS_PROMPT_V1`：模型与模型别名限制、请求 temperature、maxTokens、空会话、工具禁用、判定器全部冻结（供应商可能忽略参数，固定请求不保证模型确定性）；可变模型别名仍标识不可完全重现。唯一变量 `system_prompt`，非空 UTF-8 ≤8000 字节；多余字段拒绝，包括 `model`、`tools`、`permissions`、`code`。不自动发布/采用候选。

## 数据与内容权限

训练、搜索验证、最终留出各 1–3 条公开且用途明确批准的样本；每条包含 ID、任务组 ID、input、expected。按任务组与规范化输入检查交叉和重复；仅自动查确定可见的重复，不承诺识别全部语义近重复。样本输入/答案各 ≤2000 字节，输入不是候选代码。

分别确认公开样本用途和把训练输入、期望及实际输出用于反思的用途；简单搜索不要求反思用途授权；既有私有反馈、OTLP 正文、客户任务不自动加入。Worker context 只含训练和搜索验证，不能携带留出样本/答案/输出，甚至不保留一个可被误用的全文字段。服务端独立切分，先封存候选后运行留出；结果不能继续用于本次搜索。

普通查看只含元数据、指标、状态、摘要、实际调用与 Token 用量及证据缺口；金额尚未核算；提示词、样本、模型输出通过 `VIEW_CONTENT` 独立接口。运行/提交复用 `RUN_AGENT_EXPERIMENTS`，前端仅按 `/api/platform/me` 能力控制。

## 预算与确定性身份

服务端创建根 `TASK/optimization:<id>` 的 MODEL_CALLS 与 OUTPUT_TOKENS 账户并冻结上限；同时扣部署共享与 Agent 预算。T1 子实验还扣自己的 EXPERIMENT，反思直接归属根任务。评价预算以实际模型调用和 provider usage 为准；优化器 metric_calls 只是样本评价计数，不能冒充总模型调用。

每个样本一次 T1 配对评价发出两次真实调用（基线、候选）；合理人工验证、封存后的人工/算法留出、反思都算总额度。提交前检查计划最大调用数：`2*maxMetricCalls + 2*validationCount + 4*holdoutCount + maxReflections`。任何估计都不能替代 T2 实时原子准入。输入 Token/金额仅按实际使用披露，当前没有输入/账单金额硬上限。

评价稳定键由根 ID、候选摘要、切分、排序后样本 ID 计算；请求响应丢失先查同一意图，不生成新键重发。反思 ordinal 由服务端持久化，最多 2 个；Trace 和预算键由服务端决定。更换请求 header、Worker 或反思候选不能绕过原意图。未知保留预留，失败/重启/日期/凭证更新不重置消费。

## Worker 与协调者

Worker 只持有短期、单次运行、仅搜索状态有效的内存 claim；数据库只存摘要。不挂载供应商/机器全局密钥或 Kubernetes ServiceAccount token。EAP 固定内部 URL，用户请求不能选择回调地址。

QUEUED→SEARCHING→封存候选→HOLDOUT→COMPLETED；失联/派发结果不明进入 UNKNOWN，不能自动新建搜索。评价和反思先提交持久意图，再在事务外调用远端。只查询原评价，不对超时 POST 做通用网络重试；过期 claim、跨运行 claim、搜索结束后的 callback 均拒绝。

GEPA 关闭 merge、云跟踪、cloudpickle、进度正文日志；种子固定为 0。Worker 本地额外限制 metric/reflection 计数与时间，但后端共享账本才是跨进程授权依据。使用后端持久缓存，同一候选/切分/样本不会因内存缓存丢失取得新调用。Worker 不在启动时扫描并重放旧任务。

## 对照与建议

合理人工候选在搜索前冻结；简单搜索模式只枚举允许的文本候选，不生成或执行任意代码。基线每次实际生成，不复制历史 actual。相同额度上限下报告各自实际花费，不能写成完全等支出。

搜索阶段仅选择在全部搜索验证样本上完成的候选；失败、未运行、UNKNOWN 进入登记样本分母，缺 usage 不补零。选择后按服务端实际记录核对摘要，再执行独立留出。最终分别报告质量、Token 完整覆盖、执行/端到端时间、离线总成本、人工和算法候选服务成本。默认建议保留原配置；证据完整且满足预先登记的质量非退化与收益门槛，才可供人工评审。少量合成样本仅证明集成，不能声称算法优越性或稳定收益。
