# 已纳管实例的安全配送与按需续期

本项是 T5 的外部纳管实例阶段。认证持久化已另行验收。不是平台新建实例、任务网络执行器、所有镜像或旧模板的完整统一身份迁移，也没有声称获得原生分配代次或生产端到端 mTLS。

## 身份、授权与凭证

纳管记录绑定实例所在运行空间、名称、UID、模板及目录 Agent。控制 API 在配送前、恢复后和确认回执事务中复核这些字段，不能用自报 UID 代替核对。接入程序从运行时只读 `systemInfo.actorMetadata` 目录读取 `atespace/name/uid`，每次挑战、安装及任务鉴权重新读取，避免黄金快照保留原身份。

`generation` 是 EAP 接入身份周期，供现有工具授权、委托、操作指纹和效果记录绑定；不是底层分配代次。`credential_revision` 是短期凭证版本，正常续期只改变这一字段。实例接入授权期固定为明确启用后的 24 小时，默认凭证为 900 秒且不能晚于授权期。自动续期不延长该授权期、任何工具授权期限或额度。授权期届满需显式撤销并重新批准接入，旧工具授权失效，原账本与效果历史保留。

人工接入保持原 24 小时协议和令牌格式；自动接入是显式选择。既有未启用记录、旧模板及快照不自动迁移。关闭自动接入后回退旧程序需要原所有者的配置渠道或另一个已验证托管版本，不能把新程序的配对入口当作无条件可用回退。

## 安全配送

程序配置平台 Ed25519 公钥及只读身份目录，无平台签名密钥、模型供应商密钥或控制 API 服务账号。控制端在集群不可变 Secret 持有独立配送私钥，模板只含公钥；机器凭证不返回浏览器，也不存入模板环境、接入表或审计。标准程序进入自动模式后拒绝人工配对入口覆盖。

控制端先持久化操作 UUID、凭证版本和期限，再发带签名的 45 秒挑战。程序验签后产生内存 RSA-2048 密钥和随机 nonce；同一操作在两分钟内复用挑战。控制端用 RSA-OAEP（SHA-256/MGF1-SHA-256）加密该实例凭证，将身份、操作、nonce、版本、期限与密文一起签名。程序校验公钥签名、只读 UID、Agent、空间/名称、操作和期限，再安装凭证，返回凭证 HMAC 回执。控制端事务复核未撤销及原 UID/模板，确认后才使新凭证在 EAP 生效。

签名验证发生在生成 RSA 密钥前，未经授权的挑战不能触发密钥生成。网络请求禁止重定向，有连接、读取、总耗时及 4 KiB 响应上限。回执与审计不含凭证。

此 PoC 依赖可信控制 API、配置的内部路由与工作节点。当前内部路由采用 HTTP，签名及加密并不证明主动网络攻击下的挑战公钥来源；生产需要可信路由传输/工作负载证书或具备完整授权的原生证明。原生 `MintActorJWT` 的调用方授权仍有 TODO，未向智能体配送控制账号或开放任意 UID 签发。运行快照包含程序内存（包括短期机器凭证与临时密钥），仍处于运行环境的快照保护范围；不将“内存使用”说成物理快照无凭证。

## 续期、撤销和恢复

本阶段只在 EAP 工作流派发前按需续期；休眠或空闲期间不为续期主动唤醒，也不承诺自主出站任务、提示词实验或任务网络执行器均已迁移。恢复后，原凭证过期的实例仍可在已批准身份周期内完成安全配送，然后接收任务；旧凭证在新版本确认后立即被 EAP 拒绝。程序同时用期限及新投影 UID 检查入站任务。长任务续期、原生分配代次和全部执行入口统一仍为后续工作。

多个续期共用持久 pending 操作，确认事务幂等。配送期间不持有数据库行锁等待 HTTP，从而允许撤销先提交。锁顺序与受控工具一致：接入行在实例行之前，首次插入由实例行串行化。旧回执不能覆盖撤销或另一个身份周期。

回执丢失后保持原 pending 操作与凭证版本，候选凭证在 EAP 尚不可用；不自动生成新请求掩盖不确定结果。页面通过非秘密 `deliveryOperation` 恢复原请求；续期自动产生的 pending 也可由授权操作者按原键核对。原 pending 超过期限仍保留，需显式撤销并复核；不会清零额度或重发工具/模型任务。`runtime_delivery_requests` 留存显式接入请求与身份周期，撤销后的旧请求不能重新启用。

配送序号在同一实例记录中单调递增，撤销后不重置。程序拒绝较旧序号的挑战或安装，防止在途旧配送覆盖新版本。派发前还会加密重装当前有效凭证，以覆盖旧快照恢复的旧内存；这一步不延长期限、不创建新身份或预算，也不当成新业务意图。协议线上操作标识使用凭证版本 UUID，与页面持久请求标识分别绑定；同一个候选和已确认版本可幂等配送。

正常续期保持工具授权的身份周期、原操作 UUID、根共享预算、已提交效果和程序工具日志；原意图再查询/核对返回同一个工具存储效果，不产生新的业务效果。撤销拒绝新的机器请求，不承诺中断已在执行的外部请求。

## 使用与验收

原所有者使用支持 `EAP_IDENTITY_V1` 的程序，配置 `EAP_IDENTITY_PUBLIC_KEY`、`EAP_IDENTITY_DIRECTORY` 和只读三字段目录；复核纳管后，在接入面板选择“启用安全自动接入”。页面仅按 `/api/platform/me` 能力显示操作，服务器仍用 `PlatformPermission.DEPLOY_AGENTS` 统一保护 `/api/registry/runtime-connection/automatic`。查看与撤销沿用原权限。

编译、后端完整及相关回归、前端类型/构建、运行程序竞态测试、真实集群和浏览器验收全部远程执行。操作入口为 K8Substrate `tools/eap/identity-delivery`；独立夹具与阶段记录 `/root/eap-t5b-evidence.json`。具体成功、失败、部署版本、测试计数与未完成边界写入最新交接，不以本合同文字代替实际结果。原 T1/T2/T3/T4 夹具、UNKNOWN、模板/快照及认证持久化资源保持。
