## 真实短进程与跨实例样例

固定框架模板已通过 EAP 创建、部署、身份配送、工作流调度、观测和显式收尾。新版同实例样例共24条事件、8次逻辑执行、2次工具调用和4条代码登记；生成文件删除后，消费者执行捕获的同一份字节。

独立 [handoff-sample](../runtime/handoff-sample/README.md) 使用 LangGraph 1.2.17 与 AutoGen Core 0.7.5，在两个运行实例间传递固定公开程序。真实工作流只有一次求和工具执行，结果42、模型调用0，产生14条事件、5次逻辑执行、2条代码登记及2条双方确认关联。四次相同关联重发没有再次运行代码。

生成与执行的 Python 子进程退出后，父运行实例使用原结果和私有 outbox 补充关联；不会复活子进程，不会通过补传重新执行业务。样例镜像独立，默认框架镜像和现有实例不自动升级。观测只保存摘要/语言/大小；工作流业务输出包含固定公开程序的Base64，按业务内容权限读取，不是通用源码归档。

最终四角色×桌面/手机8个浏览器场景读取真实API，覆盖双方确认及双向跳转，没有合成关联数据。两实例显式休眠并撤销凭证后历史记录仍可读。更早的关联UI验收包含12个合成非空/分页/错误状态场景，不能与本次真实业务验收混同。

此样例没有重新测试完整后端、MySQL、前端构建、真实内核或长稳；这些范围分别采用上述已记录批次，不视为全系统统一重跑。

## 复验方式

在独立远程开发或CI环境运行后端 `mvn -B test`，前端 `npm ci`、`npm test` 和 `npm run build`。MySQL专项使用独立干净数据库，不能接入业务库；时区专项按测试URL要求配置会话。Go竞态测试需要C编译器，按原生、framework、handoff或kagent构建标签选择对应测试，不能合并标签。

Python观测模块、框架适配器及交接样例的依赖、入口和边界见各runtime目录。交付工具使用Python标准库测试。实际镜像需要核对源码、二进制、Python模块与固定依赖的摘要，并在新建样例上验证EAP创建→调度→观测→收尾。不要重放旧业务、已完成工作流或UNKNOWN记录。
