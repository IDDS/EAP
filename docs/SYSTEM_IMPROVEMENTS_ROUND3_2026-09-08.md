# 第三轮系统完善（2026-09-08）

本轮完成首页读取与信号同步分离、Agent 详情历史翻页、不可变校准历史，以及默认关闭的真实工作流 HTTP 执行链路。所有变更仅在本地，未提交、推送或部署。前两轮报告保留为历史记录，相关剩余事项以本文件为准。

## 已完成

| 范围 | 改动与效果 |
|---|---|
| AgentOps 首页 | GET 不再同步写入运营信号。独立定时同步保存成功时间与数量；首页展示实际同步时间及 NO_DATA/FRESH/AGING/STALE 状态。按钮明确为刷新视图。 |
| 观测覆盖查询 | 数据库按 Agent 聚合信号最新时间、存在性和风险；移除覆盖计算对全局最近 500 条的依赖。详情范围限定目标 Agent，事项列表在数据库过滤和限量。 |
| Agent 详情历史 | 模型、Trace、工具、正文、知识、治理六个区域独立分页；API 先按 Agent 过滤再分页，以时间/ID 稳定排序。失败保留当前页，空尾页不覆盖上一有效页，切换 Agent 清理页码并隔离迟到响应。统计注明本页口径。 |
| 评估校准历史 | 每次数据集运行生成独立 runId，持久化当时数据集版本、校准指标、评估器定义/版本/阈值、SME 标签和预测结果。读取历史不依赖当前标签或定义，不保存原始样本正文。前端支持选择历史、查看当时证据。 |
| 真实工作流 | 独立于安全预演，持久化 QUEUED/RUNNING/节点日志；冻结提交路径与配置，逐节点安全判断和 Runtime 派发，只认可匹配 taskKey 的终态。未知结果、策略拒绝、失败和超时均停止后续节点，不自动重试。 |

工作流协议、配置、请求/响应及限制见 [WORKFLOW_EXECUTION.md](WORKFLOW_EXECUTION.md)。实际 Runtime URL 纳入安全检查；配置随请求发送；执行进度检查总期限；日志使用 MEDIUMTEXT，避免合法多节点记录超出 MySQL TEXT 容量。

校准历史 API：`GET /api/evaluations/datasets/{datasetKey}/runs` 与 `GET /api/evaluations/datasets/{datasetKey}/runs/{runId}`。现有 calibration 接口继续表示基于当前标签的预览，不应替代历史运行证据。

## 数据库与配置

- V39：`eap_evaluation_calibration_runs`，不可变校准快照与数据集/时间索引。
- V40：`agentops_signal_sync_state`，信号同步状态与聚合查询索引。
- V41：`workflow_executions`，工作流快照、执行日志、队列与历史索引。
- 信号同步默认首次 10 秒、之后每 60 秒；`eap.agentops.signal-sync.enabled/initial-delay-ms/interval-ms` 可配置，保留原调度间隔属性回退。
- 真实工作流需显式配置启用开关、服务端令牌与精确目标主机白名单。默认不会调用业务 Runtime。

## 第四轮补充：编辑可靠性（2026-09-08）

- 修复画布切换、切回原流程或退出页面后的迟到节点/连线/预演/执行响应；新建流程不抢占已经切换的画布。
- 同一节点创建或连线创建期间阻止重复请求；失败允许重试，HTTP 页面保持节点标识生成兼容。
- 后端对同一工作流的节点/连线写入使用事务行锁，相同连线返回既有记录，避免重复点击造成歧义分支；不同条件仍是独立连线。不自动清理历史重复数据。
- 非 null 节点配置需为有效 JSON 对象，限制 UTF-8 60000 字节，在写库前拒绝非法或过大的内容。
- 最终验证：后端完整 182 项、前端 29 项、生产构建、H2 V1–V41 和 diff 检查通过；无新迁移，未提交或部署。
- 尚未提供多用户编辑版本冲突检测、真实执行提交幂等或真实浏览器验收；行锁不等于防止所有旧配置覆盖。


## 第五轮补充：提交幂等与编辑版本（2026-09-08）

- V42 新增节点乐观版本与执行提交键/指纹。相同身份、工作流、requestKey、参数的重试返回原执行；相同键参数改变返回 409。四线程并发验证仅创建一条记录。
- 新版控制台自动保存未确认提交的键，同标签页刷新后可重试；确认后释放。存储被禁用时只保留当前页面内重试能力。改变参数/新标签页不视为原提交。
- 新版控制台节点保存/拖动携带 expectedVersion，旧版本返回 409 并保留本地草稿；保存回包只更新版本，避免丢失等待期间的新输入，新增重新加载入口。
- 可选字段保留旧客户端兼容：无 requestKey 的调用仍可能重复新建，无 expectedVersion 的旧编辑仍可能覆盖。具体合同见 [工作流说明](WORKFLOW_EXECUTION.md)。
- 最终验证：后端 185 项、前端 34 项、生产构建、H2 V1–V42 和 diff 检查通过。未部署，尚未做真实浏览器/目标数据库/业务 Runtime 验收。
