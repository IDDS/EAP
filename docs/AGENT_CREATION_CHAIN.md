# 智能体创建链路核查

2026-09-28。

正常平台创建路径：智能体目录“创建智能体” → 填写编码、名称、责任部门/人、类别与风险 → 创建草稿身份 → 自动进入“部署与运行”配置页 → 发布并接受治理预检 → 就绪模板与实例 → 启用身份 → 试运行 → 核对模型、调用链和治理证据 → 工作流/团队执行。

本轮补齐目录创建后的导航、必填项提示和详情接入进度，避免将登记成功等同于业务执行就绪。新身份保持DRAFT，不自动启用；进度只陈述已有登记、启用状态及当前查询窗口的观测证据。

| 创建方式 | 当前能力 | 验证范围与限制 |
| --- | --- | --- |
| 零代码配置 | 系统提示词、模型、资源与出站配置，平台通用Runner | 本轮从真实界面创建及提交部署，验证模型试运行、治理决策、Trace关联和休眠 |
| 已有镜像 | 固定镜像摘要、命令、端口及就绪探针 | 既有集成验收通过；任意镜像并不天然支持平台聊天/任务协议 |
| 源码构建 | 公开Git仓库、构建目录与Dockerfile，远程kaniko构建 | 既有源码构建验收通过；依赖匿名克隆、网络可达和镜像规范，本轮未重跑 |
| 已有运行实例 | 发现、复核身份、纳管、生命周期控制，以及可选实例凭证/任务握手/受管模型与调用链 | 独立外部实例已完成工作流验收；原程序须适配协议并安全安装凭证，接入证据不覆盖所有出站行为 |

创建仍有边界：通用Runner目前主要提供模型对话/任务，不等于可视化配置任意MCP工具或知识库的完整Agent开发平台；审批阻断后不是自动恢复原部署版本，需要按已有流程重新提交；生产身份注入、凭证隔离、容灾等见运行时集成文档。不能宣称所有创建形态、异常分支和生产要求都已完成。

外部实例路径：创建目录身份 → 运行环境发现 → 复核纳管 → 接入验证中生成独立凭证 → 原程序配置与协议适配 → 验证签名握手 → 启用身份 → 工作流执行 → 核对模型及关联调用链。详见 [受控接入](RUNTIME_CONNECTION.md)。单纯发现/纳管不会自动开放任务派发。

外部程序如需工具执行前治理，可在原工具调用处接入[参考客户端与执行合同](RUNTIME_TOOL_GUARD.md)：先检查、领取一次性许可，再运行工具并回传结果。界面展示阻断、待复核和未确认回执；此能力需要原程序适配，纳管或创建目录身份不会自动为任意工具插入拦截。

参考运行程序现已支持显式启用的实例内受控计算工具，真实工作流派发、工具回执与调用链已验证。当前图形界面可保存工具类型和数字至节点configJson.eapTool，由冻结快照注入任务。执行前要求有效专属接入并确认实例工具已启用，新工作流提交不接受全局context.eapTool。旧模板和默认镜像不会自动升级；平台共享凭证实例尚不能使用此工具节点。详见[工具节点配置](WORKFLOW_TOOL_NODES.md)。详见[Runner工具模式](../runtime/agent-runner/README.md)。
