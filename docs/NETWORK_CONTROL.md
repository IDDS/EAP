# 智能体拓扑与控制

工作台的“拓扑与控制”显示平台逻辑关系，连线并不表示实际网络流量。实例是否可控，以控制面板的目标实例检查和执行回执为准。

## 看图

- 使用搜索框定位任意节点，默认只显示它及直接关联节点。关闭“聚焦关联”可查看全图。
- “展开画布”覆盖整个窗口，Esc 退出；滚轮或加减按钮缩放，拖动空白区域平移，“适应画布”恢复全图范围。
- 控制关系为蓝色虚线，工作流编排关系为绿色实线。同端点、同平面的重复关系合并，展开关系明细查看全部声明；全图控制关系采用共享主干，走线避开无关节点，窗口展开时使用六列布局。主干及每行干线只绘制一次，避免大图重复虚线绘制导致卡顿。
- 布局尺寸随节点数量增长，所有节点都可通过搜索或全图访问。节点本身不再提供受固定坐标限制的拖动。

## 下发命令

选择智能体后，控制面板读取 `GET /api/control/agents/{agentId}/targets`，列出实例、可用命令、不可用原因、派发开关和重试上限。只有一个可用实例时自动选中，多个实例时需要明确选择。

无实例、离线、HTTP 心跳过期或已退役时禁止提交；导入实例只提供状态检查、休眠和恢复。平台创建的原生实例另支持快照回退；HTTP 实例提供相应控制协议命令。后端适配器仍校验命令和导入实例身份，客户端列表不能代替服务端授权。

前端按 `/platform/me` 的 `operateInstances` 能力控制下发及重试，服务端沿用 `PlatformPermission`。每次请求显式指定 `runtimeInstanceKey`，不会因所选实例不可用而改投其他实例。HTTP 指定实例也检查心跳租约。

只有 `ACKED` 显示成功；`FAILED` 显示执行失败及原因；入队、派发中显示等待确认。请求超时为90秒，与实例控制页一致，以等待后端默认60秒RPC。网络异常时先刷新消息确认结果，不应盲目重复下发。HTTP 的 ACKED 表示接收端返回 2xx，具体配置和限流行为由接入程序实现；回执丢失后重试复用 commandKey 和 Idempotency-Key，接收端也必须去重，不能据此承诺所有接入程序恰好执行一次。

## 查看消息

- 数据源仍为全平台最近20条控制消息；默认在其中筛选当前智能体，可以切换全部智能体。
- 每页4条，滚动区域固定330px，消息再多也不会拉长画布。详情默认收起，可展开查看编号、目标实例、派发/确认时间及完整结果。
- 重试需有操作权限、未达到服务端上限，且当前所选实例和命令仍匹配并可用。服务端按命令加数据库行锁串行重试，重新检查智能体退役状态；重试审计使用当前认证操作者和 RETRY_CONTROL_COMMAND，原始命令发起者保持不变。
- 这不是完整审计历史检索；查询更早记录需使用审计相关功能，不能把“最近20条中无记录”理解为从未执行过命令。

验收记录见 K8Substrate `artifacts/eap-topology-control-20260929/`；前后端测试、构建、浏览器均在远程 PoC 集群执行。

## 控制状态与进程健康的边界

原生实例的RUN_HEALTH_CHECK当前读取运行环境控制元数据；ACKED表示查询成功，不证明应用进程健康。2026-09-29真实验收发现进程已停止/HTTP502时，控制元数据仍RUNNING，EAP相应显示运行中。自动识别缺口尚未修复。显式快照回退和恢复已通过，详见RUNTIME_CAPACITY_ACCEPTANCE.md；不要依据这类状态检查自动重放未知业务。
