# 普通用户使用路径优化

首页新增处理待办、跟进任务、查看业务成果三个入口；待办入口滚动到事项列表，不虚构个人归属或待确认总数。

任务列表改为任务编号、要处理的事情、执行进展、业务结果和执行结果，使用中文状态。模拟创建、技术用量和手动执行状态标记收进管理操作，明确手动标记不会启动真实执行。该折叠属于界面呈现，不替代权限控制。

任务详情优先显示任务说明、执行结果、业务确认说明和按当前状态生成的下一步建议。业务确认继续调用原接口，要求打开说明弹窗；确认后刷新列表与详情。加载中或加载失败时禁用确认按钮。四类技术证据默认折叠，保留关联不足、截断、金额和治理证据边界说明。

验证：前端62项现有测试及构建通过。浏览器验证三个首页入口、事项定位、中文状态、管理操作显隐、任务详情、四类折叠记录和业务确认弹窗取消；390px页面与抽屉无横向溢出。测试未修改线上业务记录。此次仅前端改动，没有建立新的执行调度、收益核验或权限能力。
