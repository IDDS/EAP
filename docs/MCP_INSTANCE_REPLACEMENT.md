# MCP 实例替换与历史隔离

EAP 的安全替换路径是：确认原任务状态，经 EAP 删除旧实例，保留旧身份记录，再使用新的创建请求生成替代实例。新实例具有新的 instanceKey 和 Actor UID；原创建请求、原执行请求及历史观测各自保留，不迁移为新实例的执行。

这与同 UID 的进程重启、快照恢复不同。普通恢复不代表重新授权或自动撤销原凭证，仍须遵守原租约、配送序号和任务回执。本轮实测与限制见 [验收记录](evidence/mcp-rebuild-20261020/README.md)。

## 各层责任

| 层次 | 已有保护 | 本轮验证方式 |
| --- | --- | --- |
| EAP 创建 | 固定创建请求绑定原版本和 UID；撤销后拒绝再创建或接入 | 原实例经 EAP 删除后，原创建请求返回 409 |
| 实例登记 | 删除后保留 OFFLINE 身份记录、原创建意图和撤销状态 | 真实 EAP API 与只读数据库核对 |
| 任务派发 | 完成的相同 requestKey 返回原运行记录，不在替代实例重新执行 | 同批已完成请求返回原 Run，执行数量和原观测不变 |
| Runner 配送 | 新进程不继承旧 RSA 私钥与 challenge；安装需匹配当前投影身份 | 远程 Go 测试重建 Runner 状态，覆盖同 UID 和新 UID |
| MCP 租约 | 使用当前安装凭证和 UID；轮换后拒绝旧凭证 | 远程 Go 测试，原续期、取消和身份变化测试继续通过 |
| 持久意图 | 同 UID、同私有日志下的 UNKNOWN 原任务返回原回执 | 远程测试模拟进程状态重建，不启动 MCP 服务、不改写日志 |
| 观测接收 | 当前 UID 不匹配或凭证撤销时拒绝；已签发实验 Trace 不能被其他实例借用 | 隔离后端测试确认拒绝且没有 Span、工具记录或预算写入 |
| 普通 Trace | 原始 Trace/Span 按实例命名空间转换 | 两实例提交相同合成 MCP 载荷的后端测试，原记录保持不变 |

## 操作与验收范围

创建、删除、调度、查询、休眠和撤销均使用 EAP 接口。没有直接修改 Substrate Actor 身份、旧运行登记或全局 UNKNOWN 占用。

真实验收使用同一固定镜像和版本的两个新实例，各执行一次无模型合成任务。删除旧实例后创建替代实例，核对原执行、原输出摘要、原 Trace 和工具记录；四角色分别读取两次运行的观测。替代实例完成后通过 EAP 显式休眠并撤销身份。

只有本批已明确完成的请求用于幂等返回验证。不得把此步骤推广到结果未确认的创建请求、UNKNOWN 任务或已关闭批次；这些情况应查询原意图和回执，不换键重跑。

本轮没有在真实集群中强制进行“同名、同 instanceKey、新 UID”重建；该 UID 漂移拒绝来自后端替身测试。也没有导出真实 Runtime 凭证进行负向请求；旧凭证拒绝来自隔离测试。进程重启测试重建 Runner 对象并复用测试日志，不等于真实进程崩溃、磁盘回滚、快照克隆或跨节点灾备验证。

MCP 名称清单仍是可信宿主配置和观测命名规则，不是通用工具执行权限。通用恢复、跨任务共享连接、Kagent MCP 执行、HTTP/SSE 及 eBPF/gVisor 对照仍需独立完成。自动回收没有纳入本轮验收，旧全局 LEGACY/UNKNOWN 保护保持。
