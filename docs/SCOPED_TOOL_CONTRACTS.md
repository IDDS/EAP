## 工具合同与边界

`controlled_counter_increment / poc-counter-v1` 是专门用于验收权限与持久效果的计数工具。只允许增量1–100的整数、`poc_` 开头的明确对象；根授权最多8个新对象、8个明确接收实例、32次提交，最长1小时，不能超过持有实例凭证期限。没有通配符、业务文本、任意URL、代码执行或模型调用。计数是受控数据库中的真实持久写入，不是运行程序自报“成功”，也不是客户业务系统的效果证明。

根授权由 `PlatformPermission.GOVERNANCE` 能力管理，创建主体来自登录身份。查看元数据复用 `VIEW_CONSOLE`。前端只读取 `/me` 能力，不解析JWT。实例机器通道仍使用既有实例专属凭证，控制台JWT不能代替它。

持有实例绑定Agent、接入代次和纳管UID。创建时固定明确接收实例的UID/Agent绑定；委托不接受Agent自己覆盖策略版本、工具合同、根预算、效果来源或消费计数。父与接收方本地工具策略都须允许同一工具。

## 委托与共享消费

根任务预算标识为 `tool-root:<rootGrantId>`。委托最长4级、每级只能收窄父授权的对象、接收方、单次增量、累计次数与期限。子额度是额外上限；多个兄弟和重新委托不复制根额度。提交时整条链的 `usedCount` 增加，各不同Agent的工具策略/共享账本各扣一次，同Agent多层不会重复计费；部署共享账本只扣一次。根任务预算创建后不能被普通预算编辑接口重置或提高。

策略每次保存都会增加版本，使引用旧版本的授权链失效。撤销父授权无需改写子授权行，提交时沿祖先复核。页面显示自身状态和可见祖先撤销，不把“尚未过期”当作当前执行许可；缺祖先或版本/额度尚未复核时明确提示提交前复核。

锁顺序：作用域全局锁→按实例键排序的连接/纳管行锁→按Agent排序的本地策略锁→预算准入锁。此受控工具以确定性数据库事务保证一致性，没有声称已验证生产容量或消除全局锁开销。

## 意图、提交与证据

先保存不可变操作意图，再尝试一次提交。`(rootGrantId, operationId)` 唯一，指纹绑定持有实例、接入代次、委托、对象和参数。相同请求读取原操作，不产生第二次提交；同根操作换父授权、实例或参数返回冲突。换一个新操作标识仍消耗原根和全部适用预算。

工具服务在同一事务中复核当前授权链、行为/数据治理、本地策略和共享预算，再更新计数对象、记录效果UUID、保存终态与工具观测。这一受控工具的数据库提交点构成版本屏障；不能把检查时获准、许可领取、控制取消ACK或Agent回执当成通用第三方工具提交屏障。

| 证据 | 含义 |
|---|---|
| `TOOL_STORE_VERIFIED / COMMITTED` | 本受控工具存储已持久提交，带effectId、提交后计数、operationId和Trace |
| `TOOL_STORE_NO_COMMIT / REJECTED` | 当前操作经受控存储核验未提交；不代表工具系统之外没有其他行为 |
| `UNKNOWN` | 持久意图存在，缺少已确认终态；原意图不自动重发 |
| `RUNTIME_REPORTED` | 既有普通工具执行方回执，不提升为独立效果证明 |

预算明确拒绝时，提交事务回滚本地策略消费和工具计数，随后保存已确认拒绝。其它存储/进程故障保留UNKNOWN。查询持有作用域锁，不跨越尚在执行的提交事务；查询是只读核验，不触发恢复执行。一般第三方UNKNOWN对账与恢复属于T6。

运行程序只发送一次工具POST，磁盘意图在发出前保存；超时、未知、错误作用域/操作/Trace或缺少可信效果字段都不伪装成功。重复工作流任务和休眠恢复读取原日志。原始Trace由operationId派生，实例通道只做一次命名空间转换，任务Span关联真实工具操作；辅助观测失败不导致重发工具。

## API和产品入口

入口：智能体目录→运行环境→接入验证→工具权限→作用域授权与效果核验；工作流工具节点可选择“受控计数与效果核验”。节点冻结grantId、operationId、resourceId和delta。稳定操作标识对应一次业务意图，另一次工作流运行使用相同标识也不会增加计数；新业务意图需显式设置新标识。

- `GET /api/registry/runtime-tools/scopes?instanceKey=...`：最近30条授权、30条操作及最多32个计数对象。
- `POST /api/registry/runtime-tools/scopes`：治理主体创建不可变根授权，字段grantId、holderKey、resourceSet、recipientSet、maxDelta、claimLimit、expiresAt。
- `POST /api/registry/runtime-tools/scopes/revoke`：治理主体撤销指定授权，既有效果保留。
- `POST /api/runtime-access/v1/tools/scoped/delegate`：持有父授权的实例请求收窄委托，额外字段parentGrantId。
- `POST /api/runtime-access/v1/tools/scoped/execute`：实例提交稳定操作，字段grantId、operationId、resourceId、delta。
- `GET /api/runtime-access/v1/tools/scoped/operations?rootId=...&operationId=...`：实例查询自己的持久操作，无重试效果。

参数采用严格schema，未知字段拒绝。旧check/claim/receipt接口不能设置新证据字段；新效果只由工具存储可信路径写入。V60追加表和字段，旧记录继续标为runtime-reported，旧模板/运行实例没有自动升级或授权。

## 受控计数标识符语义：2026-10-06 T5-C

仅由受控计数存储先验证类型、所有权、作用域、祖先策略与参数边界后，内部安全检查把grantId/operationId/resourceId当作合同标识符，把delta当作有界整数；原始参数仍进入指纹、共享预算、提交效果和审计。独立测试确认合法UUID数字片段可误判PHONE/PII，本项按合同语义处理该元数据。

普通工具检查API仍检查所有参数，即使工具名相同也无调用方豁免；手机号形UUID与密码敏感内容在普通API仍拒绝。没有重新解释旧REJECTED/UNKNOWN/COMMITTED、增加额度或重置意图。其他业务工具需逐项定义内容及标识符合同。本轮新增3项针对性回归、最终完整498/89和真实原计数工作流一次存储效果通过。
