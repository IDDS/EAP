# 镜像与源码发布的专属实例身份

新发布的 RUNNER、IMAGE、SOURCE 版本统一采用 PER_INSTANCE_V1。镜像与源码程序必须实现平台身份协议；接入确认是“可运行”的前置条件。历史版本不会因读取或同一请求重放而迁移。本阶段关闭新发布入口的共享凭证注入路径，旧实例及旧模板的逐批替换和共享密钥停用继续属于 T5-D2。

## 程序接入合同

程序监听端口 80，实现 POST /eap/identity/challenge、POST /eap/identity/install，并遵循[自动安全接入](RUNTIME_AUTOMATIC_IDENTITY.md)的签名挑战、内存 RSA-OAEP 配送、只读原生 UID/模板复核及 HMAC 确认。可基于 runtime/agent-runner 制作镜像。支持一个健康端点并不代表支持身份协议；协议不支持或确认丢失时停留失败/待核对状态，不能回退共享凭证。

模板仅注入 Agent 标识、网关地址、冻结的配送公钥、身份目录和工具能力标志；不注入 EAP_TASK_TOKEN、EAP_GATEWAY_TOKEN、EAP_OBSERVABILITY_TOKEN 或机器凭证。原生 systemInfo.actorMetadata 三字段目录是只读的。程序仅在本实例收到已确认短期凭证后才能接收受限派发和访问平台机器接口。任意自定义镜像的用户预置内容仍需另外审查，本合同不证明其镜像内部不存在秘密材料。

## 版本与创建意图

首次发布冻结镜像摘要、公钥与专属身份模式；源码先完成集群内构建并固定推送摘要，再创建模板。镜像为六个阶段，源码为七个阶段（含构建镜像）；两者均在创建实例之后确认专属身份，随后显示可运行。配送配置不可用、派发未启用或自定义服务端口不是80时，新发布在产生构建/原生创建副作用前拒绝。

实例复用[平台创建合同](PLATFORM_RUNTIME_IDENTITY.md)：创建前持久保存请求与版本，按原生 Create 回执 UID 绑定所有权；回执不明确时保留原意图，不按名称接管、不重新创建。身份确认失败后只能核对原 UID 和原配送操作。重试接入阶段不能创建第二个实例。撤销保留身份、创建历史及预算，原创建请求永久取消。按需短凭证续期不延长原24小时授权、不重置工具根或预算。

## 历史兼容与迁移

同一 requestKey 的原配置先核对保存记录，再应用新发布的身份要求。既有旧端口和旧身份记录可按原请求读取；参数改变仍返回409，不把原记录改成新身份。已存在的旧发布及其在途阶段保留原合同；旧版本不能通过额外实例接口新增会话。要迁移应明确发布一个支持身份协议的新版本，验证效果和预算，再安排旧实例退出；不能原地改写已完成、失败或 UNKNOWN 的原意图。

2026-10-07只读盘点记录47个可见智能体、24个部署记录、56个登记、59个原生实例，观察范围全部连接且未截断。22个发布记录为旧身份：RUNNER13、SOURCE6、IMAGE3；其中包含失败的历史发布，不等同22个在线实例。24个可读取的实例模板含三种旧共享凭证名称中的至少一种；该数不包括其他配对凭证，也不保证没有无实例引用的遗留模板。两个原 EXECUTION_UNKNOWN 工作流保留，未发现未结束任务网络任务。盘点只存公开元数据、环境变量名称和配置摘要，不存模板值或凭证。

## 页面与权限

/agents/substrate/capabilities 返回 instanceIdentityAvailable，配送不可用时页面暂停新发布。镜像/源码表单说明协议要求并固定端口80；版本列表区分“专属实例身份”和“旧身份版本 · 待迁移”。按钮仍只按 /platform/me 能力控制，后端授权来自 PlatformPermission；前端不解析 JWT 或按角色名判断权限。

## 验收范围

本阶段使用独立镜像和固定提交源码夹具，模型预算为零；每个实例执行一次受控计数，核对工作流回执与工具存储确认效果、独立身份、跨实例拒绝、请求幂等与参数冲突。四角色 API 和桌面/390px 浏览器只读复验，浏览器业务写入零。收尾休眠、撤销身份与工具根，保留两个效果和原预算、旧实例/模板、原 UNKNOWN 和模型消费。实际测试与部署证据追加到项目交接，不用本文合同替代实测。

当前仍是内部可信 HTTP 路由 PoC。旧模板全量迁移、共享密钥停用、通用恢复/发布取消、分级观测、策略完善、调度公平/老化/画像以及稳定 Agent 调优收益仍未完成；原演示视频未重录。
