# 运行大屏组件接入验证

日期：2026-09-11。本轮为本地实现与验证，尚未部署。

## 已实现

- 锁定 `@adminlte/vue 0.7.0`、`d3-zoom 3.0.0`、`d3-selection 3.0.0`，增加 D3 类型声明。
- 5 个 KPI 使用官方 `LteSmallBox`；健康概览使用 `LteInfoBox`；模型分布面板使用 `LteCard`。自有封装提供中文操作、可访问折叠与大屏样式。
- 不注册 AdminLTE 全局插件，不导入 Bootstrap/AdminLTE 全局 CSS，不调用全局主题能力。样式按组件适配；处理现有全局 `.small-box` 白底及伪元素对官方组件的覆盖。
- 拓扑使用 D3 提供 50%–400% 连续缩放、鼠标拖动、滚轮缩放、适应画布、定位选中节点、键盘方向键平移和 Home 复位。Vue 管理节点与变换属性，D3 管理交互，不同时操作同组子节点。
- 数据刷新保留视口和选中对象；原有搜索、分页、来源更新时间、失败保留、暂停和隐藏页保护继续保留。
- 按用户偏好保留持续流动动画，标注为“潜在调用路径示意，非实测流量”；沿用数据新鲜度保护，暂停/隐藏页停止，减少动态效果偏好下禁用。

## 验证结果

- `npm run build` 通过；`npm test` 54/54 通过；`git diff --check` 通过。
- 本地浏览器连接现有本地后端验证，未向外部 demo 上传数据。
- 1920×1080 截图核对 KPI、健康信息盒、模型折叠面板；390×844 无整页横向溢出。
- 实际点击放大：100% → 125%；选中控制节点后定位：150%；手动刷新后保留 150% 和选中节点。
- 键盘 ArrowLeft 得到 `translate(50,0) scale(1)`，Home 恢复 100%；暂停按钮使动画 `animationPlayState=paused`。
- 模型面板折叠/展开按钮及 `aria-expanded` 正常。
- 返回控制台后 `.command-metric` 为 0，`html[data-bs-theme]` 未设置，1440 宽度无横向溢出。
- 构建产物的大屏 JS chunk 为 80.03 kB / gzip 27.90 kB；该值是本轮完整路由 chunk，不是新增依赖体积。未进行 60 分钟稳定性或生产环境性能测试。
