# 任务证据关联与大屏业务价值

2026-09-11，本地实现，未部署。

## OBS-04 第一阶段

新增只读 `GET /api/tasks/{id}/evidence`。按四类记录明确的 task_id 读取模型、工具、治理、价值元数据，不按Agent名称、相同Trace或相近时间扩大关联。每类最多100条，额外探测一条以提示截断；相同任务但Agent冲突的记录不返回内容，只返回隔离数量。agent_id缺失的记录可按task_id展示，但明确标注身份未提供。关联依据不等于认证身份，也不是新增租户权限模型；沿用现有API只读角色规则。

任务列表增加诊断入口，query taskId 支持直达。抽屉分开呈现执行状态与problemResolved业务记录，列出四类来源、稳定事件键、时间及逐条金额；没有数据明确表示未找到关联。Trace可下钻并返回原任务；Trace上下文可能含其他任务，页面没有声称完整单任务执行图。

抽屉切换/关闭隔离迟到响应；刷新失败保留已加载记录并提示。append-to-body避免路由动画容器裁剪。

## 大屏价值展示

根据用户要求，将“任务与业务结果”调整为“业务价值与成果”，展示业务标记已解决、业务结果待确认、可度量价值事件与登记收益。ManagementSummary新增 resolvedTasks、unresolvedTasks、unconfirmedTasks，由同一时间窗内任务的problemResolved分别计算；不从SUCCEEDED推导已解决。

收益采用既有登记值，缺少价值记录或币种不可比较时显示未知；不跨币种合计，不展示ROI。当前还没有独立的收益核验工作流，因此使用“登记收益”，不称独立审计确认收益。
