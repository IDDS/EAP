# 共享预算与准入控制（T2 有界实现）

主任务仍是 Agent 调优、调度与权限治理；本项为跨执行路径的预算底座，下一项是受限提示词优化及独立留出集。工程方法来源见 `research/agent-system-methods-20261002/implementation-plan.md`，不能据此声称联通或字节项目方案已经完整部署。

## 账户与单位

同一受管执行同时检查部署共享、智能体、已验证任务、正在执行的实验账户；范围越小只能进一步约束。当前平台没有真实租户实体，PLATFORM/default 是本部署共享额度，不能当作多租户隔离。所有已有账户初始不设上限，新用量从启用后累计，不导入或清零旧账单。

| 单位 | 准入预留 | 结算与未知处理 |
| --- | --- | --- |
| MODEL_CALLS | 每个已承诺派发 1 次 | 已知/未知回执均计 1 次承诺；不等于成功计费调用 |
| OUTPUT_TOKENS | 请求明确声明的最大输出 | 供应商完整报告实际输入和输出时，以实际输出结算；缺失时保留全部输出预留 |
| TOOL_CLAIMS | 一次受管工具许可 | 与工具策略消费在同一事务内提交；不是外部效果或费用凭证 |

输入 Token 只记录，不预留；没有金额硬预算。明确 max_tokens 或 max_completion_tokens（只能一种，1–8192 整数）、单个输出，才能进入模型派发。当前提示词实验自身仍限定最多六次调用和每次输出不超过 256。

## 准入、重复和恢复

数据库持久化账户、预留、唯一调用意图、持有者和唯一结算，所有副本使用同一个数据库行锁。每个账户须满足 `已用 + 在途预留 + 安全余量 + 本次预留 <= 上限`；未设上限仍累计统计。模型预留使用独立事务，确认提交后才调用上游，不把上游 HTTP 放进数据库事务。

稳定 X-EAP-Invocation-Key 防止同键再次派发；实验强制使用已保存 Trial Trace，不接受换请求键重置预算。新运行程序传 X-EAP-Task-Key，服务端通过工作流已保存的派发步骤或任务网络记录验证归属；X-EAP-Task-Id 验证普通任务归属。旧客户端无任务键时仍扣部署/智能体额度；无稳定调用键时不能保证跨重启单调用去重。旧模板不自动升级。

供应商响应丢失、不完整流、用量缺失或超时保留输出占用，不用 0 冒充未知。进程在提交预留后退出，DISPATCHED 仍占用；UNKNOWN 不自动过期、不跨日重置，没有人工解除入口。持有者不匹配、重复或迟到覆盖回执均受约束。供应商超出声明上界时记录真实输出并冻结受影响的输出账户，调高限额不能抹去违例。

网关以 `X-EAP-Admission-Outcome: REJECTED` 证明预算检查在派发前拒绝；已有调用意图/冲突用 RECORDED，其他错误为 UNKNOWN。运行程序不能仅凭 HTTP 429 或 5xx 推断未执行。已证明预算拒绝的实验以 FAILED 停止，不污染全局实验队列为 UNKNOWN；未证明的上游错误仍保留未知。

## 权限与页面

权限只在 PlatformPermission 定义 manageBudgets；治理管理员和平台管理员可设置额度，其他控制台角色只读。前端读取 /me 能力，不解析 JWT。配置用 expectedRevision 比较更新，操作者来自认证主体，预算变更存 budget_limit_changes；调小限额保留全部已用/预留，不按日期自动补额度。

入口“成本与价值 → 共享预算与准入”，可通过 `/management?section=budget` 访问。页面显示三个部署指标、范围额度、已用/预留/余量/上限、进度和最多 100 条执行意图，表格限高；手机设置表单可滚动。按钮双激活不重复提交，失联后先刷新核对版本，身份切换清理旧数据。

## 覆盖边界

本项不改变原 FIFO 顺序，尚无预算公平排队、老化、阶段调度、总 Token/金额硬上限、未知人工对账、多租户预算实体或长任务租约迁移。工具预算计许可，不证明工具实际外部效果。旧机器凭证对智能体归属的信任边界仍存在，统一实例身份/安全配送/续期继续作为主任务。

启用参数 EAP_BUDGET_ENABLED=true。默认未来配置式 Runner 与任务网络 Runner 可更新到已测固定镜像；现有模板和已完成夹具不自动迁移。不要重应用整份认证清单或重启 emptyDir Keycloak。
