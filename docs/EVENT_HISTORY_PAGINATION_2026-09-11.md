# 治理与价值历史分页

新增 `/api/governance/data-events/page`、`/api/management/value-events/page`，沿用 page/size/keyword/from/to/order 查询合同，数据库完整计数；治理 status 表示策略动作。查询和排序使用 observedAt + id，旧任务/审计仍使用 createdAt + id。

支持精确 agentId、endpointKey、eventKey 上下文。价值记录的 agentId 包含主智能体和共同贡献归属，使用 EXISTS 避免重复记录/总数；贡献明细按当前页批量读取。价值币种独立过滤，无混币加总，价值记录不接受伪造的状态字段。

前端治理事件和价值记录接入统一历史表格；路由上下文或币种变化后清理旧行并重新查询。时间范围独立于上方摘要，未选择时查询全部时间。移除基于旧局部数组的价值空提示。旧接口及摘要/漏斗数据流保留，不能将历史表格分页误认为所有摘要计算已完成规模改造。

验证：213后端/62前端测试通过，前端构建通过。集成测试创建505条价值记录和111条治理记录（事务回滚），覆盖跨旧上限、共同贡献、币种隔离、事件发生时间、精确上下文及字面关键词。现有事件时间、Agent/端点和贡献索引沿用，无新增迁移。子串检索和深页offset尚未进行大规模性能验收。

待办：物理观测明细、治理预检决策等仍需逐项补齐服务端历史分页；OBS-04任务采集关联与业务价值核验仍未完成。
