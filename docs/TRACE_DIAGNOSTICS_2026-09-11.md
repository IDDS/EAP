# Trace 诊断第一轮交付

2026-09-11，本地已验证，未部署。关联事项：OBS-01/02/03、UI-02，见 [持续清单](OPTIMIZATION_BACKLOG.md)。

## 改动与边界

新增 V45 两个 nullable 生产时间列 `started_at` / `ended_at`，OTLP 导入与 Span API 返回对应字段。仅从生产端纳秒字段解析，不以接收时间、duration 或历史 observedAt 回填；缺失、负数、解析失败保留 null。结束早于开始保留原始证据供前端报告异常。数据库列精度微秒，浏览器显示精度毫秒。

Physical 页面选择 Trace 后显示并发时间条、失败筛选、父记录缺失/祖先循环提示和 Span 元数据详情。缺失时间及派生记录不画伪时间条。已观测跨度为有效时间记录的最早开始至最晚结束，不是 duration 总和，也不是完整任务墙钟耗时保证。500 条读取上限显式提示；本轮没有实现服务端一致性全量 Trace 查询。

同页切换 Agent/endpoint/Trace/event 时清空旧范围的事件证据并重新加载；请求版本隔离迟到成功/失败，卸载忽略回包。当前范围刷新失败保留旧记录且显示错误。已有 HTTP 拦截器的通用错误提示未改变。

App 路由动画增加单一 DOM 容器，解决 DashboardView 多根节点无法动画的警告。未改变路由权限或业务操作。
