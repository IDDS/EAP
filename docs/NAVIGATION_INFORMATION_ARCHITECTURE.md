# 平台导航与页面信息组织

2026-09-28。面向业务能力命名，正常导航、标题、配置选项及说明不突出底层产品品牌。内部路由、API、执行方式枚举及历史任务标识保持兼容。

## 功能顺序

工作台、运行大屏是常驻入口。其余按工作流程排列：

| 分组 | 页面 |
| --- | --- |
| 接入与资产 | 发现与接入、智能体目录 |
| 编排与执行 | 工作流编排、团队与计划、异步任务、业务任务记录 |
| 运行与观测 | 运行与遥测、基础设施监控、知识调用链路 |
| 评估与优化 | 质量评估、反馈与改进 |
| 治理与审计 | 策略与审批、安全响应、责任与伦理、审计日志 |
| 成本与价值 | 成本与价值（直接入口） |

分组只负责展开，不隐含跳转。全部功能入口有图标和文字，图标不承担唯一含义。当前页面、父分组和面包屑保持一致；智能体详情归属智能体目录。

## 页面层级

- 工作台保持待办优先；增加“平台能力导航”，复用同一目录，展示各功能用途。
- 团队与计划优先显示计划、步骤、执行结果；团队与成员资料折叠收纳，仍可展开。
- 异步任务默认展示状态和任务历史；有执行权限的用户通过“新建任务”展开表单。
- 执行方式展示“常规执行 / 隔离沙箱”，资源池展示“常规执行池 / 隔离任务池”。
- 宽度 900px 以下使用带完整文字的抽屉导航，点击功能后关闭，支持 Escape；桌面仍支持折叠侧栏。
- 搜索保留旧名称作为内部关键词，结果展示新的业务名称。

## 维护规则与边界

目录定义集中于 frontend/src/navigation/catalog.ts，图标映射于 navigation/icons.ts，菜单为 PlatformNavigation.vue。新增页面应同步目录与用途说明，不能复制另一份导航结构。权限仍由服务端能力控制。

保留历史验收数据名称、任务编号、实例标识、原始错误与技术日志；这些内容可能含底层名称，不能为了隐藏品牌伪造业务记录。本次不更改接口合同、运行流程或已有演示视频。不是全站重新设计，也不代表所有页面触摸编辑体验已全面验收。
