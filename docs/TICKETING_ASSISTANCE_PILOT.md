## 第一阶段：指定工单的只读辅助

选择一种目标系统和一个低风险工单类型。业务人员输入系统内已有的工单标识，EAP 使用受控的只读身份查询该工单的明确授权字段，展示来源、查询时间、当前可见状态和所用身份范围。系统可以生成摘要和处理建议草稿，用户查看来源与不确定项后自行决定如何处理。首版不创建、更新、关闭工单，不发通知，不自动执行建议。

一次试点运行至少要关联：系统与环境、工单标识、查询时间、可见范围、EAP 任务/执行标识、建议版本及人工确认结果。原始正文、附件、人员信息及建议的保留和访问规则由目标业务明确；不得在示例、日志或仓库存入客户数据或凭据。工单内容属于待处理数据，不能改变系统权限、调用目标或审批规则。

当前 EAP 的工作流执行目标、计划目标/上下文说明及步骤标题属于控制台可见元数据，不受工作流结果 `viewContent` 保护；不得将工单敏感正文或凭据填入这些字段。工作流提交上下文保存在执行快照，成功节点的原始输出保存在步骤记录；结果接口的内容权限不等于数据未落库。真实试点前需确认上述数据的分级、保留周期、数据库及备份访问范围，不能据合成测试推断符合目标企业的要求。

## 查询结果与安全边界

| 查询观察 | 页面/记录如何表达 | 不得推断 |
|---|---|---|
| 按目标系统约定的唯一标识取得授权可见记录 | 显示来源、查询时间、当前字段和记录标识；建议与原事实区分 | 不能把当前状态当作历史创建回执，或把建议当作已执行 |
| 未找到或不可见 | 显示查询未找到可见记录及已知范围；业务状态保持未确认 | 不能断言工单不存在、从未创建或可重新创建 |
| 401/403、连接失败、超时、响应超限或格式不兼容 | 显示读取失败或权限不足，原状态保持未确认 | 不能沿用旧记录冒充本次查询成功，也不能切换身份或绕过授权 |
| 接口返回多条、分页未完整或标识与原请求不一致 | 标示歧义及覆盖限制，交由业务人员核对 | 不能自动选一条作为唯一工单或确认外部效果 |

工单接口按具体产品、版本和环境验证：唯一标识及作用域、读取权限、归档/删除的可见性、分页/过滤、更新时间与一致性。客户端不接受任务输入指定任意 URL 或凭据；连接目标、身份和网络出口由平台配置及目标环境策略约束。敏感内容须按现有中央权限与目标系统授权双重控制，不能仅隐藏前端按钮。

## 辅助结果和人工确认

草稿至少包含：引用的已知事实、信息不足或未确认项、拟议处理步骤和需要人工确认的事项。无可核对来源时明确标注，不能补造事实；工单正文中的命令、提示或链接均不授予 Agent 权限。业务人员确认的结果与模型生成的建议分别记录；未确认、拒绝或修改建议均不能计为已解决。

## 效果与运营口径

试点前共同冻结任务范围、统计周期、同类人工处理基线、样本选择和业务确认标准。至少记录：查询尝试/成功/未确认、建议生成/人工确认/拒绝/修改、人工处理耗时、可见模型与其他成本及其覆盖情况。成本缺失、估算或币种不可比时标记原因；未经确认的节省时间和金额不作为已实现收益。具体样本量与目标值由业务负责人按场景确定，不预设通过率或 ROI。

现有价值事件并非独立确认流程：确认人可由上报方填写或由连接器配置，系统不会验证该人是否逐条确认。不能仅凭事件存在、来源标识或登记金额认定工单已解决或收益已实现；试点须另外留存经业务负责人确认的结果和测量依据。

试点期间指定业务、平台和安全责任人；工单不可见、权限撤销、结果不一致和模型输出异常均有人工接手路径。第二个团队或独立环境应重新核验身份、数据访问、配置和责任，再记录复制时间及差异；复制计划本身不代表工单接口或授权随之迁移。

## 验收顺序和证据

1. 确认系统、接口版本、环境、只读身份、目标字段、数据分类和责任人；未知项显式记录，不保存凭据或客户正文。
2. 在远程隔离环境用合成工单和受控 HTTP 服务验证：唯一命中、不可见/未找到、多条与分页、权限拒绝、超时、响应超限、格式异常、任务内容注入和权限撤销；记录请求方法，确认没有外部写入或通知。
3. 在获授权的目标环境，以限定样本验证真实身份、字段和来源；记录人工复核，不以模拟结果代替真实系统验收。
4. 对照人工基线和成本覆盖出具试点评估；再由第二团队验证复制及运营责任。

未来若需要创建或更新工单，应先单独验证目标接口的授权、调用方幂等键及有效期、原请求与业务标识的关联、纯只读查证和取消后的行为。读取不到、超时或执行方报告失败均不能证明未提交；只读查证不得重发写请求。已有[工单接口能力记录卡](research/business-result-contracts-20261015/connector-assessment-card.md)可用于逐接口登记这些边界。
