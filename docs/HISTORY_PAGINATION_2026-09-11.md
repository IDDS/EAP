# 历史记录服务端分页

运行任务和审计日志新增 `/api/tasks/page`、`/api/audit-logs/page`，数据库按条件分页和计数。旧列表接口保留兼容，其他页面不受响应格式变更影响。

参数：page 从1开始、size 1–100、keyword 最长200字符、status、order asc/desc，以及 ISO 时间 from/to（含开始、不含结束）。返回 items、totalElements、page、size。按 createdAt 与 id 同向排序，保证同时间记录顺序稳定；实时新增期间 offset 分页不提供跨页快照保证。

审计检索操作者、动作、资源、Trace；任务检索类型、调用方、输入与结果。关键词通配符按字面转义。时间/状态与关键词共同过滤，数据库总数使用相同条件。V46为两张表增加时间和状态/结果复合索引；子串搜索仍可能扫描记录，尚未宣称大数据规模性能验收。

前端统一提供时间范围、状态、关键词及排序，默认每页10条，可选20/50/100；条件变化回第一页、旧请求结果忽略、卸载后不更新、失败不显示旧行、总数缩减时校正页码。时间查询按浏览器本地选取并转UTC发送。

验收：新增集成测试覆盖115条审计记录、跨100条读取、无重复ID、字面关键词、状态与时间边界，任务23条数据库分页，以及非法页码/条数/状态/排序/时间窗返回400。其他列表仍使用已加载数据分页，后续逐项迁移。
