# Trace 标识来源

Trace 诊断对每条已保存的 Span 分别展示 Trace ID 和 Span ID 的来源：

| 来源 | 含义 |
| --- | --- |
| 上报方提供 | 该字段在接收时非空；不表示格式、真实性或任务归属已验证。 |
| 平台回退生成 | 接收时字段缺失或空白，平台使用既有的回退标识。 |
| 来源未知 | 迁移前记录、部分派生记录或不能确定来源的记录。历史记录重放不会被推断为来源已知。 |
| 来源冲突 | 同一记录在后续上报时观察到不同的已知来源。 |

前端为模型事件构造的派生记录会标为来源未知，因为标识可能沿用事件，也可能由界面回退生成。标识来源只是观测元数据，不能单独证明业务成功或 Trace 与原请求的关联。

V101 为已有记录和未提供新字段的旧写入设置 `UNKNOWN` 默认值。旧版本与新版本混合运行、并发更新同一记录或数据库恢复时，来源与冲突提示的完整性尚未验证；不能因为未显示冲突就认定没有冲突。上线前应验证实际升级、回滚和混合版本策略。

验证范围：隔离 H2 后端完整回归和打包通过；隔离 MySQL 8.4 已验证包含 V75、V86 Java 迁移的 V100→V101 升级；前端完整测试、类型检查和构建通过。实际部署后的浏览器、混合版本和并发场景仍待验证。
